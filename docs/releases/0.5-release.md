## Scope

This candidate implements the permanent repairs defined in
[`v0.5-AUDIT-REPAIRS.md`](../change-specs/v0.5-AUDIT-REPAIRS.md), based on the
complete v0.4 iteration audit. It repairs the active task bank, allocation,
generation packets, import contracts and review warnings; it does not generate,
accept, alter or finalize student assessment items. Original-year locked forms
and all historical catalogs remain preserved.
