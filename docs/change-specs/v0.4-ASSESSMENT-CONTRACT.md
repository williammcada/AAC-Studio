# AAC Studio v0.4 — Assessment Contract

**Status:** Accepted local assessment constraints. Do not generalize them to other assessment products.

## Product rules

- Grade 5–7 admissions forms: eight interchangeable forms per grade, fifteen one-point items per form, no calculator.
- Numeric, symbolic, short-label, ordered-pair, or multiple-choice response only; no more than two multiple-choice items per form.
- ELL-friendly wording and no US-specific cultural context.
- Preserve strict interchangeable-form overlap rules as an AAC-local requirement.

## Acceptance checks

| Check | Result |
| --- | --- |
| Every exported form matches its grade, item-count, and response constraints | Not run |
| Equivalent forms meet the local overlap requirements | Not run |
| Import/export validates project and design revision before accepting content | Not run |
